# 湖大 · 长沙项目机会地图

为湖南大学大一学生整理的项目、导师、社团、比赛和开源实践入口，目标是通过可运行项目和真实反馈准备暑期实习。

## 在线页面

https://zhouyunding.github.io/hnu-career-opportunity-map/

源码仓库：

https://github.com/zhouyunding/hnu-career-opportunity-map

## 更新原则

- 优先使用学校、学院、团委、赛事主办方和开源社区的官方来源。
- 每次更新都记录核验日期，并区分“现在可联系”“下一周期关注”“报名已截止”。
- 公开的招募入口不代表一定有名额；报名年龄、资格、截止日期和指导安排要向组织方确认。
- 不把纯讲座、宣传活动或培训机构包装成可持续项目机会。
- 更新 `index.html` 后，通过 GitHub Pages 自动发布。

## 本地预览

直接用浏览器打开 `index.html` 即可，无需安装依赖。

## 页面包含

- 校内导师、实验室、学生社团和双创资源
- 长沙开源活动、全国远程开源项目及周边参考
- 搜索、筛选、机会状态、适合度和联系动作
- 官方来源、联系模板和两周行动建议
